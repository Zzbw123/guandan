# P5e 固定策略池下标签均衡目标的等发牌配对研究

2026-09-29，总控事前设计。版本gd-p5e-paired-label-balanced-v1。执行结果另写P5E_ACCEPTANCE.md，本协议不按结果改写。

## 问题与估计对象

在同一mixed固定池、同一随机初始化与同一发牌预算下，比较P5d已验收的ordinary与label_balanced训练目标。两臂均只训练current决策；规则、编码、网络、团队终局奖励±1、完整合法候选、探索率和角色日程保持一致。frozen仍为随机初始化固定副本，无教师预训练、辅助损失、动态策略池或外部权重。

label_balanced在每个实际minibatch同时出现±1时，正负类各占损失一半；单类退回普通MSE。权重与日志精确定义沿用P5D_PROTOCOL.md和已冻结P5d实现。它改变拟合目标，不是原期望回报的无偏修正；分数不能解释为校准胜率。没有成功标签的批次不会生成成功样本。

估计对象为相同发牌预算下目标干预的总效果。目标变化后访问轨迹、样本、Adam更新次数和计算量可能变化，这些是干预后的变化，不再人为补齐到同样本或同更新。三个固定初始化只能给出有限条件下的重复结果，不作跨初始化总体稳定性声明。本假设来自P5c事后诊断，本轮协议在新研究运行前冻结，不将原诊断改称因果证明。

## 冻结训练预算与顺序

- 初始化314510、314511、314512；每初始化ordinary/label_balanced两臂，从头重置模型、Adam与全部RNG。使用相同初始化是为了配对和ordinary历史兼容检查，不按过往优劣选择其中最优者。
- 每作业1600手/400wave，共9600次主训练执行；六作业共用开发seed100000..101599，仅1600份发牌。第n手级牌2+n%13、起手n%4。
- 固定mixed角色日程沿用P5a每16手四种角色组合与四个focal座位。epsilon=.1、lr=.001、batch_size=256、chunk_size=1024、num_envs=4。
- CUDA float32、确定性算法、TF32关闭，使用scripts/run_gpu.ps1记录的解释器；策略仅接收PlayerObservation与完整合法Action列表。
- 训练顺序按初始化分块随机、块内随机两臂，seed314550；开发顺序同结构seed314551，验证臂顺序seed314552。不以墙钟时间比较算法速度。
- 保存initial、wave1/2/3/4、wave200、final(wave400)；中间检查点只作恢复/审计，不参加选择。前四wave供独立数值重算，覆盖四类角色block。没有早停、追加训练或超参数搜索。
- 每个训练/评测子作业最长3600秒；异常保留全部数据并停止，重试用全新目录，禁止按行为结果换种子。模型评测spawn启动60秒、请求2秒硬截止；固定基线仍是返回后2秒检查，不声称所有调用均硬隔离。

## 开发、验证与唯一候选

所有六作业完成并绑定六个final SHA后才开始评测。开发复用108100..108125：26个原始发牌组，13级牌各2组，每组8个旋转/换队变体；六候选各208局对greedy，共1248局。报告每个初始化的label_balanced−ordinary配对差和条件于初始化的描述性区间。开发已查看，不用于挑选候选或新增独立验证声明。

事前指定label_balanced-314510为唯一主候选，ordinary-314510为同时期配对对照；其他初始化不进入新验证。拟用208000..208064，须历史artifacts JSON/JSONL/gzip seed字段扫描零命中、零解析错误及输入哈希核验后方可启动。封存测试payload只核对哈希，不读取其内容。

新验证65个原始发牌组，13级牌各5组，每组8变体，对greedy/random/team各520局；两臂各1560局，总3120局。开发加验证共4368局。原始发牌为聚类单位，相关变体和多对手不能当独立发牌。bootstrap按级牌分层、原始发牌成组，5000次，seed314553。

唯一主要绝对比较为label_balanced-314510对greedy：胜率>=55%，95%成组区间下界>50%，区间非退化，且零失败、非法动作、超时。绝对门槛不能以相对弱对照改善替代。即使通过本轮验证，也不自动替换greedy或调用保留测试；最终测试须另行预注册。

label_balanced−ordinary配对差、random/team和行为比例为预设次要点态描述，不作多重比较校正后的总体显著性声明。配对差区间含0不证明等效；退化区间只复述观察样本，不证明总体胜率确定。合法过牌和出完漏选按既有行为口径报告分子/分母，两策略访问的机会不同，不能由比例差直接归因。

208000..208064一经执行登记为已查看，不因结果负面回收为新数据。既有验证至207000..207064保留原标签，9000000..9009999继续封存。

## 冻结、核验与交付

正式运行前核验P5d交付及历史冻结证据，完成协议JSON往返/预算/候选/seed边界/新守护载入/完整8769候选及故障回收测试。冻结协议、执行源码、测试、控制器审计源码、输入和随机顺序，保存源码/输入ZIP；输出不覆盖。

总控独立重演9600手训练与4368局评测，核验发牌、角色、完整候选、动作索引、学习样本归属、终局标签、探索和打乱RNG、批次顺序、正负计数、实际权重、分母、损失聚合和更新计数。全量批次日志核验不等于全量历史梯度重算。

核验三对初始模型/Adam/RNG相同、冻结池不变、检查点源/运行时/配置/谱系和唯一final候选；ordinary与P5b mixed的全部400wave原日志字段、四个共有检查点核心张量/Adam/RNG/计数逐位一致。P5d专用检查点仍绑定目标；本次P5e运行驱动由独立预注册来源表绑定，不能将两个来源范围混同。

六作业各前四wave，共24个真实wave，独立全候选网络表达式核验策略选择，并按重建样本以独立每样本权重表达式重算损失、梯度和Adam，核对各wave终态；容差rtol3e-4/atol3e-6。报告实际单类/双类覆盖。不声称重算所有2400wave历史梯度或策略分数。全量评测完整牌谱、行为分母、成组区间和配对差独立复算；篡改负例须覆盖目标/权重/批次/标签及统计数据。审计缓存绑定输入、源码和预注册哈希，不能复用无来源缓存。
