# P5f 完整候选动作排序预训练配对研究

2026-09-29，总控事前设计。版本 `gd-p5f-ranking-pretraining-v1`。本包执行提升方案第一步，工程、教师拟合及开发对局分别验收。训练前冻结本协议、实现、测试和控制器源码。无新独立棋力验证，无封存测试，无自动晋级。

## 估计对象与目标

固定四座 greedy-v1 演示及 gd-hand-v1 / gd-features-v1 / DMCNetwork 参数结构。两臂从同参数随机初始化开始，各对同一演示语料完整遍历一次，FIFO64观察/批，最后余数也更新，每观察仅一次；Adam lr=.001、eps=1e-4、capturable=True，float32 CUDA、确定性算法、TF32关闭、CPU线程1、chunk1024。三个初始化314560/314561/314562，六作业不继承旧权重，不按结果追加训练。

冻结前数值修订记录：首轮工程测试（p5f-tests-gpu-v1.log）发现平移不变目标在理论零梯度附近的float32舍入差约1e-8，被默认Adam eps=1e-8放大为约4e-4参数差。总控在任何拟合/胜率结果产生前，将两臂eps统一固定为1e-4以抑制该数值敏感性；损失、学习率与原数值验收容差保持不变，失败日志保留。不宣称与历史P3f优化器逐位兼容，也不根据开发成绩搜索eps。

模型原始标量z=output_fc(relu(hidden_fc(relu(state_fc(s)+action_fc(a)))))。regression对tanh(z)做教师minmax[-.8,.8] MSE（教师全平分时目标0），先候选平均再观察平均。ranking目标为每观察 `logsumexp(z_all)-logsumexp(z_optimal)`，再观察平均；教师最优集合按确定性float64 score与最大值精确相等定义。合法候选及同编码物理副本全部保留，不合并、不采样、不截断；候选编码相同必须有相同教师分数，否则失败。单候选或全体最优的ranking项/梯度严格0，仍计入观察分母及既定Adam步；有动量时零梯度步不保证参数不动。优化算法每批恰一次Adam。

ranking以分块无梯度前向构成完整logits，再计算全局稳定logsumexp及解析dL/dz，随后分块重前向累计梯度。该双遍算法必须与稠密autograd的损失、全参数梯度、单步Adam相符；不能每块单独归一化。推理两臂都使用原始z的首个最大值，避免tanh数值饱和制造并列；这与旧P3f实现不逐位等价，本研究不作该兼容声明。两臂目标和输出映射是配方干预，保留同参数数量/数据/批次/更新预算，不声称等计算量。

## 数据及固定顺序

训练1600份发牌100000..101599，第i手level=2+i%13、start=i%4。一次生成并保存教师牌谱，六作业复用，不能称9600份独立数据。语料生成与加载核对完整候选、GreedyAgent动作、终局牌谱及计数；训练API只接收PlayerObservation与完整Action列表，不传seed/full state/replay。

拟合开发26份发牌108100..108125，level=2+i%13、start=i%4；与训练不交叠，但属于已查看开发区间，不能称新验证。开发对局同26份发牌，每级两组、每组4轮转×2换队，对greedy/random各208局，每模型416局，六模型2496局。random沿用既有评测policy_seed271828及其派生规则；不额外测试team。保存所有结果、测量、完整牌谱及行为分母。

训练顺序按初始化分块、块内两臂随机，seed314563；开发作业顺序seed314564。所有六作业final权重冻结后才进行拟合开发及开发对局；不挑中间checkpoint或最高初始化。每作业保存initial、batch1、batch2、final（如果final与batch2同位置，只保留各有名称的独立保存）。检查点含语料manifest哈希、下一批位置、完整Adam/RNG/配置/源/版本/设备绑定，仅成功批次边界允许保存；恢复只在同确定性运行时承诺。

## 工程前置与小样本可拟合检查

工程语料用前13份训练发牌，不增加独立训练样本。每手取最早两个多候选观察（不足不补），按手序组成固定小样本；所有候选完整。单独初始化314560，ranking训练固定512次全小样本batch，禁止扫lr/轮次/换样本。训练前后记录全量raw评分、最优集合命中、损失与权重hash。达到多候选命中率>=99%才启动正式六作业；未达到则结束本包为可拟合检查未通过，不自动扩量。此512步是独立开发工程探针，不继承给正式模型，不算正式1600手预训练。

工程测试：两目标稠密损失/梯度/Adam、平移不变、单候选/全平分、并列最优、重复编码、8769候选、分块边界、异常/非有限拒绝；专用检查点错误目标/语料/源/hash/计数/Adam拒绝；新进程batch2恢复到固定batch4与连续运行的模型/Adam/RNG及非时间日志逐位一致；更新中途失败后拒绝继续或保存，需新建实例恢复。新看门狗真实载入和超时/崩溃/非法动作回收通过后进入正式训练。

## 开发指标与下一阶段门控

保存小样本、训练探针（同每手最早两个多候选，前13手）及全部开发教师轨迹的最优集合命中率；总观察/多候选分母分开，报告每副牌等权均值及候选数>1024、手牌<=5、一次出完等层。normalized regret使用原教师分数范围；全平分为0。无法达到某分层样本量只报告分母，不补挑。

ranking三个初始化均需：训练探针命中>=99%、开发多候选观察命中>=95%、对greedy开发胜率>=45%、对random>=80%，才标记 `READY_FOR_RL_STUDY_DESIGN`。同时报告三个regression结果及条件于各初始化的配对差，不用单个最好者绕过门控。门控不是棋力晋级；未过为 `PRETRAINING_GATE_NOT_MET`，保留全部负结果，下一步按拟合/分布问题单独设计。

开发对局按级牌分层、原始发牌成组bootstrap5000次、seed314565；ranking−regression按同发牌组配对。所有区间为已查看开发数据上的描述，条件于固定初始化；三初始化不证明总体稳定性。绝对正式晋级门槛仍>=55%、非退化95%下界>50%，本包不执行该正式验证。保留测试9000000..9009999封存。

## 冻结、审计和失败处理

冻结前核验P5e交付输入、历史注册源；正式输出必须新目录。运行前后source_sha256和ZIP核对一致，原验收文件不改写。每个训练/评测子进程7200秒总截止，推理spawn60秒/请求2秒硬截止；基线沿用返回后2秒检查。失败保存目录、错误和已完成数量，不换种子补跑；实现修复需新版本目录并保留旧失败。

总控独立重建所有教师演示、核查完整候选与等价编码教师目标；六作业每批顺序/观察/候选分母及覆盖复算；六作业首两个真实批次以独立网络/稠密目标表达式复算全部梯度和Adam，容差rtol3e-4/atol3e-6，不称所有历史梯度已重算。完整开发牌谱、指标、行为与成组bootstrap独立复算，并做关键输入篡改拒绝。工程通过与预训练开发门控分别记录，P5仍PARTIALLY_ACCEPTED，model_promoted=false，P4/P6后置。
