# P3h 教师偏好辅助损失单条件配对试验

日期：2026-09-26。总控先固定本协议、源码、输入权重和日程，再执行正式GPU实验。本轮研究问题是：在相同教师初始化后的DMC中加入固定辅助回归，能否保留教师偏好并改善对贪心的胜率。结果可以为负；不扫权重、不按开发结果选模型。

## 输入、干预与计算

三个初始化314380/314381/314382，继承P3f对应teacher前200手raw权重；旧文件必须匹配P3g交付回执及本轮外部SHA256。每个初始化分control和aux两个条件，均重新构造Adam、Python策略RNG、torch CPU/CUDA RNG，仅传递模型参数。

两条件各续训600手，seed100200..100799，level=2+(seed-100000)%13，起始座位=(seed-100000)%4。同步4环境、epsilon=0.1、lr=0.001、batch=256、chunk=1024。三个初始化和两个条件重复使用同600份发牌，不是3600份独立发牌。原200手不重训。

对每批B个DMC决策观察，完整动作集合A_i，选择动作a_i及终局团队回报r_i：

`L = (1/B) sum_i (Q(o_i,a_i)-r_i)^2 + lambda * (1/B) sum_i [ (1/|A_i|) sum_a (Q(o_i,a)-t_i(a))^2 ]`。

control的lambda=0，aux的lambda=0.1，为本轮唯一未调优条件。t为原P3f贪心score在完整候选中min-max映射到[-0.8,0.8]；全相等、单候选均取0。该辅助目标包括绝对评分回归，可能与终局价值目标冲突；它不是概率或最优价值。每观察先平均全部候选，然后观察等权。辅助数据就是该DMC批的观察；不另取教师回放训练，不额外更新Adam。每批先累加DMC及全部候选辅助梯度，再且仅再做一次Adam更新；尾批保留。

匹配环境手数；轨迹、更新次数、监督标签数和墙钟耗时可能不同，结论属于整个训练程序变化，不声称等计算预算。全部动作保留；探索随机选牌也保留完整候选用于辅助损失。玩家只收到PlayerObservation与完整Action列表；发牌、全状态、研究回放留在环境和审计侧。

## 日程与判断

训练顺序由314403打乱，开发评测顺序由314404打乱。六模型各在同一既有开发seed108100..108125、13级牌各2组、每组8轮转/换队变体，对greedy评测208局，总1248局。开发已看过，结果用于配对描述；不能伪称独立确认。

训练前唯一指定aux-314380最终权重为主验证候选，control-314380为同发牌对照。新验证seed204000..204064，13级牌各5组，每组8变体，对greedy/random/team每条件1560局，共3120局。先扫描历史JSON/JSONL/gzip中的seed字段，确认新验证未执行。仅原始发牌组是独立抽样单位；级牌分层、发牌成组bootstrap5000次，seed314405，报告点态95%区间。配对差值先在同发牌内相减；三个初始化区间各自条件化，不混合为总体显著性。

唯一主验证指标为aux-314380对greedy胜率；预设门槛点估计>=55%、区间下界>50%、非退化、零失败/非法动作/超时且工程审计通过。其余指标和差值为次要描述。即使达到门槛也只记录VALIDATION_GATE_PASSED，实际晋级另行决策；9000000..9009999保留测试继续封存。

辅助机制固定诊断：重建teacher-314380阶段一回放中的前128个多候选观察，六个最终模型对全部候选评分，报告教师top-1一致率、标准化遗憾和候选MSE。选择由轨迹顺序确定，不能按评分结果改变；它是有限诊断子集，不是全状态无偏估计。
