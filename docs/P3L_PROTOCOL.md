## 问题、依据与唯一变化

P3k同一教师来源13个多候选观察中，六个最终模型的0.1倍centered辅助梯度范数中位数仅为DMC的0.83%–1.24%，同时cosine有正有负。观察来源有偏、样本小，逐观察比值不等于训练批次比值。这只提出“固定0.1是否使辅助梯度相对量级过小”的可检验假设，不认定为棋力失败原因。未用已查看验证局选择权重或初始化。

对照constant：原P3j中心化目标，g = gD + 0.1 gC。

唯一处理normcap：同一个完整训练batch先分别计算DMC均值梯度gD、完整候选按状态等权centered均值梯度gC，令d=||gD||₂、c=||gC||₂。范数在所有参数上以float64归约；alpha是detach常数，不对alpha求导。

- 若d<=1e-12或c<=1e-12，则alpha=0。
- 否则alpha=min(1.0, 0.1*d/c)。
- 联合梯度g=gD+alpha*gC，只执行一次原Adam更新。

单候选C梯度仍为0，观察仍进入batch状态分母；不能重采样、截断候选或剔除单候选。目标比例0.1、权重上限1.0和零范数阈值一次固定，不扫描其他值。该规则可能上调或下调相对原0.1的权重。

由Cauchy不等式，alpha*c<=0.1*d，因此在d>阈值时 dot(gD,g)>=0.9*d²。这个界限仅针对同一batch未经Adam预条件的一阶方向；不能据此保证有限步长的损失下降、Adam更新方向、长期稳定或棋力。零梯度分支单列，不伪造比值。
