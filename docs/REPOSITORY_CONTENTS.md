# GitHub 仓库内容范围

2026-09-30，用户指定将本项目推送到 `https://github.com/Zzbw123/guandan.git`，并选择“源码、文档和轻量实验报告”。

## 已纳入版本管理

- `src/`、`scripts/`、`experiments/`：规则、环境、策略、训练、评测与研究工具源码。
- `tests/`、`configs/`：测试与实验配置。
- 原开发方案、`AGENTS.md`、`README.md`、`docs/`、依赖及构建配置。
- `artifacts/` 中的轻量报告、预注册、审计回执、交付回执、来源及检查点元数据、测试日志、报告 CSV 和 PNG/SVG 图表；具体匹配规则见根目录 `.gitignore`。

## 保留本地的产物

训练权重（`.pt`、`.pth`）、原始逐局/逐步记录（`.jsonl`）、压缩原始数据（`.gz`）、源码及输入快照（`.zip`），以及未列入白名单的实验中间 JSON 数据不上传。`artifacts/checkpoints/`、`artifacts/replays/`、不完整检查点和轨迹数据也保留本地。环境、缓存和凭据文件不纳入版本管理。

这些文件没有被删除或移动。仓库中的 manifest、binding、预注册和审计报告可能引用上述本地产物；引用及既有哈希按原样保留。克隆仓库后可以阅读报告并使用源码开展新的运行，独立复算历史实验及恢复既有模型仍需要对应完整本地产物和兼容运行时。仅凭仓库内的轻量报告不能完成历史实验的全量复核。

## 研究状态

本次是现有项目的版本管理与发布操作，未新增训练、评测或棋力验收。最新阶段和未完成门槛以 `docs/STATUS.md` 为准；各历史报告保留其生成时的状态。P5f 尚在执行中，既有棋力结论仍为 `NOT_ESTABLISHED`，没有模型晋级；桌面端及完整比赛环境仍待实现。

GPU 入口 `scripts/run_gpu.ps1` 支持用环境变量 `GUANDAN_GPU_PYTHON` 指定已验证的解释器。报告中记录的绝对路径和运行时属于原机器的历史证据，换机器运行需配置实际存在且满足要求的环境。
