# P3f 单一前期训练条件对照

2026-09-26，总控设计；执行入口在任何正式训练前冻结本文件、全部运行源码、测试及前置诊断证据。规则 gd-hand-v1、gd-features-v1、网络结构和完整合法候选不变。研究和训练优先，桌面端仍后置。

## 问题与前置条件

P3e增加训练手数仍未通过对贪心的验证门槛。本实验检验：固定环境手数时，将前期DMC替换为贪心教师偏好回归，随后进行同样的DMC训练，是否改善开发表现和固定候选验证表现。先执行 P3F_DIAGNOSTIC_PROTOCOL.md；评分数值/动作/编码碰撞或实际回报/梯度诊断失败则阻断训练。通过诊断不证明编码充分性或全局正确。

## 唯一变化及预算

三组配对初始化314380、314381、314382，每臂800手，共4800手执行，800个唯一训练发牌seed。两臂均使用seed100000..100799，第i手level=2+i%13，start=i%4。每个初始化内相同初始网络参数。

- control：前200手现有DMC，后600手现有DMC。
- teacher：前200手四座贪心演示并进行完整候选偏好回归，后600手现有DMC。

双方在200手处重新建立相同初始化的GPUTrainer，仅载入第一阶段模型参数；Adam、Python/CUDA随机数和采样器状态统一重新初始化。因此control是具有共同阶段重置的DMC对照，不能称为P3e连续DMC的复刻。第一阶段的行为分布和标签共同构成一个训练程序干预，不能把效果单独归因于某一因素。

教师对所有观察（含单候选）及全部合法候选逐一调用冻结GreedyAgent.score。每观察min-max线性归一至[-0.8,0.8]，全相同则全零；FIFO每64个观察更新一次，最后不足64也更新，每观察只出现一次。目标为每观察内部完整候选MSE的平均；分块1024仅控制显存、不丢候选。该目标是启发式偏好分数，不是胜率、校准价值或分类式行为克隆。

两臂统一DMC配置epsilon=.1、lr=.001、batch256、chunk1024、4同步环境；CUDA float32、确定性算法、CPU线程1、TF32关闭。手数预算匹配；候选评分数、样本数、Adam更新数和墙钟时间不保证匹配，必须分臂分阶段报告。禁止依据中途结果增加轮次、修改超参数或更换候选。

## 证据与失败处理

每手训练保留完整研究回放、终局摘要、候选计数与设备证据；模型训练只接收观察和合法候选。phase1独立权重/Adam payload及SHA；phase2载入前核SHA、记录参数逐字节摘要、空Adam和零计数。最终标准检查点只记录其真实600手DMC状态，外部lineage记录总800手，两者不得混写。

评测保留所有结果、耗时、完整候选数、牌谱及行为统计。GPU子进程启动上限60秒、单决策2秒、每job2400秒、单手1000步；失败保留目录并整包判失败，不删除异常局。新输出目录须不存在；运行前后源哈希与ZIP一致。总控从磁盘复算全部统计、每手回放、候选覆盖、阶段重置及历史源保护，做篡改负例后出具独立验收。任何中止须报告已实际完成的数量和原因。
