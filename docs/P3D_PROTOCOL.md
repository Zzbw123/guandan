# P3d 首轮固定预算 GPU 候选训练与独立验证

2026-09-26 总控事前冻结；协议版本`gd-p3d-validation-v1`。本包检验固定预算候选相对主要基线的表现，并补齐外部推理超时隔离。工程验收与棋力验证分开签署；保留测试集仍不启用。

## 训练预算与候选选择

从头初始化一个模型：seed314360，epsilon0.1、lr0.001、batch256、chunk1024、num_envs4。使用已验收gd-gpu-wave-v1算法，开发seed104000..104399、400手、100wave；级牌2+i%13、首攻i%4。模型/Adam/编码/规则不改。每25wave保存检查点，最终100wave为唯一评测候选，禁止按验证胜率挑选中间检查点或追加训练。预算为首轮有界研究预算，不声称已经足够训练高水平策略。

训练进程整体限时1800秒，超时杀死并阻断本轮结论；失败不删记录。最终模型SHA在任何验证对局前写入evaluation-preregistration。使用CPU完成规则和特征，CUDA完成推理、损失、梯度和Adam。恢复工程已由P3c验证；本包记录更长的实际训练耗时和更新数，不重新标为长期稳定性通过。

## 推理隔离

持久spawn子进程只接收PlayerObservation与完整合法Action列表；环境、发牌seed、全信息回放不进入请求。该进程加载绑定hash的检查点并执行完整CUDA评分、按原候选顺序argmax；返回候选索引、数量和计时。父进程所有GPU请求有2秒硬截止（含IPC及推理）、启动60秒截止。超时、崩溃或非法输出使实例关闭，terminate/kill并有界join；不回退为随机动作，不删除失败局后继续统计。它是本地故障隔离，不是对恶意代码的操作系统安全沙箱。

已审查的固定基线在环境进程运行，仅作返回后2秒软时限检查。每局1000步护栏。外层评测进程整体限时1800秒，覆盖环境/基线意外挂起，但不把基线软时限称为逐调用硬隔离。

## 验证日程与数据边界

验证seed201000..201064，共65个原始发牌组，2..A每级5组。冻结前扫描项目已有实验seed记录未发现该区间已用；选定后不得根据结果替换。P2已查看200000..200129仍为旧验证数据；9000000..9009999保留测试集继续封存。正式评测后201000..201064标为已查看，后续调参不能把它当未查看测试集。

每组4次轮换×2次交换策略队伍，共8变体，起手座位固定0。模型+模型分别对greedy+greedy、random+random、team+team，各520局，总1560局。三场景使用相同发牌组；轮换和换队变体相关，不能当独立样本。复用P2 trial结构/发牌变换/基线RNG派生，model为epsilon0。policy_seed271828；它不是环境发牌seed。

## 主比较和统计门槛

唯一确认性主比较为模型队对greedy队。先求每个原始发牌8变体的胜率，再按级牌分层、在层内重抽原始发牌组；5000次bootstrap、seed314361、95%百分位区间。沿用P2已验收cluster_bootstrap/summarize_matchup实现。报告胜率、相对50%的百分点差及区间、组数、SD/中位数/分布和地板/天花板/退化情况。不采用独立伯努利局数区间，不做事后可选停止。

验证门槛须同时满足：所有1560局完整且零错误/非法/超时、全部回放通过、候选与源码hash绑定、greedy主比较胜率点估计>=55%、非退化95%区间下界>50%。通过仅记`VALIDATION_GATE_PASSED`，尚需独立保留测试与产品门槛，不自动替换主基线；否则`NOT_ESTABLISHED`，不能解释为证明模型与基线等价。区间退化即使点估计100%也不凭零宽区间晋级。

random/team为预设描述性次要对照，不做多重显著性排名。65组是资源预算选择，不声称达到预设80%检验功效。统计假设为原始发牌独立抽样、同级牌组可交换、全部变体完整；先检查缺失/重复、层样本数和组分布。bootstrap无需正态/方差齐性假设，不适用t检验正态性筛选，不按结果换检验。任何缺失/失败都阻断有效统计，所有场景如实报告。
