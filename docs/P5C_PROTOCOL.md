# P5c 固定池负结果的奖励分布与同状态动作评分诊断

2026-09-27，总控事前设计，版本 gd-p5c-pool-diagnostic-v1。来源为已验收 P5b，诊断由其负结果触发，属于探索性事后机制研究；本协议在计算本包新统计前冻结，不冒称原实验事前假设。

## 问题与固定范围

检查 mixed 配方是否伴随学习标签/动作分布不平衡，以及在相同可见状态和完整合法候选上，mixed 最终模型是否更偏向过牌。标签与动作的相关性不能证明过牌导致胜负，也不能证明样本数量或固定池结构是唯一原因。

只读 artifacts/evaluations/p5b-pool-v1 的六份完整训练日志及六个 final 模型；初始化314510/314511/314512，每个selfplay/mixed。新增训练0手、对局评测0局；不读取验证牌谱，不使用任何新验证或保留测试。保留原规则/特征/网络/目标和完整候选。

## 全量训练分布

重新重演六作业共9600手的全部决策，核对seed/级牌/起手/角色/合法候选/选择索引/样本归属/状态摘要/终局奖励。按作业、400手区间、16手周期中的角色block输出计数；按current学习决策统计正负标签、pass/play、可选过牌与强制过牌、一次出完机会及漏选。另报告按current座位-牌局计的胜负：selfplay每手4个，mixed每周期分别2/1/1/1个，不把决策数等同独立样本量。

## 同状态交叉评分

每作业固定选n=400*q+r（q=0..3,r=0..15）的64手，共384次来源牌局执行，跨作业只有64份发牌。各手只选current的首个决策、首个有pass且有play候选的决策、首个一次出完机会；重合状态合并并保留类别，缺失机会记录为缺失、不补挑。最多1152状态，不按模型分数筛选。

六个final模型全部交叉评分这些状态的完整候选，CUDA float32、确定性算法、TF32关闭；平局取首项。逐状态保存全分数、argmax、过牌与出完选择、max(pass)-max(play)、max(finish)-max(nonfinish)，缺失候选类型用null。汇总按来源作业与被测模型给出分母、比例和平均间隔；同状态mixed-selfplay差条件于初始化，仅作描述，不给独立样本p值或总体区间。分数不是校准后的胜率，完整终局标签只用于审计统计，不能进入模型输入。

## 验收

正式输出使用新目录，运行前冻结协议/新源码/测试和输入哈希，保存源码ZIP；结束及独立审计后再次核验。旧P5b注册/产物、P5a与P3历史证据维持原hash。不覆盖失败目录。

总控独立从原日志重算全部按角色的样本/动作/正负标签计数，独立重建384手与全部选择状态、全候选及行为分母；六模型所有选择状态用独立线性层表达式及不同分块复算CUDA分数（rtol3e-4、atol3e-6），核验argmax一致与全部聚合。覆盖无机会、单候选、强制过牌、全分母、非有限/长度错误、分数/来源/选择状态篡改拒绝等边界。新测试与项目GPU回归无跳过后出具验收。

本包结论为 ACCEPTED_POOL_COLLAPSE_DIAGNOSTIC_V1，仅覆盖诊断工程。P5整体仍PARTIALLY_ACCEPTED、model_promoted=false；greedy保留，P4/P6后置。后续训练配方根据结果另立协议，不能追加P5b预算或按本轮状态筛选最终候选。
