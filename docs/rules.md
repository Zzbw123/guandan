# 单副牌规则规格 gd-hand-v1

本文件是项目的可执行规则契约。采用常见两副牌掼蛋核心；尚未取得完整官方原文逐条认证，不宣称是官方规则认证实现。用户未指定地方变体时依此开发。完整升级赛与进还贡在 P6 单独冻结。

| 编号 | 固定行为 |
|---|---|
| R01 | 108 张实体牌，ID 0..107；每副 54 张，S/H/C/D 各 2..A，随后小王、大王。座位 0/2 同队、1/3 同队，行动按 0→1→2→3。 |
| R02 | 每家 27 张；初始级牌 2..A 可配置。首攻座位由 reset 显式指定，默认 0；实验负责平衡首攻。无进贡。 |
| R03 | 非连续牌型排序：2..A（去掉级牌） < 级牌 < 小王 < 大王。红桃级牌单出按本身级牌比较。 |
| R04 | 两张红桃级牌可替代 2..A 的任意点数/花色，不能替王。单张不能任意声明。对子及以上允许全配牌组成（双配牌可声明任意普通对子），作为本项目明确选定的变体。配牌解释必须随动作记录。 |
| R05 | 单张、对子、三张；三带二由不同点数三张与对子组成，所带对子可为同色王对。大小王不能组成混王对。 |
| R06 | 顺子恰好 5 张，连对恰好 3 对，钢板恰好连续 2 组三张。按自然点数比较，级牌不升位。A 可低或高；允许 A2345、AA2233、AAA222，禁止循环 KA2。 |
| R07 | 同点炸弹 4..10 张；同花顺恰好 5 张；王炸为两大王两小王。优先级：王炸 > 10..6 张炸弹 > 同花顺 > 5 张炸弹 > 4 张炸弹 > 普通牌型。相同长度炸弹用级牌升位排序；同花顺按自然顺序，无花色大小。 |
| R08 | 普通牌型只压相同 kind、相同张数且 main_rank 强度严格更小者。同花顺实体集合亦可声明普通顺子，保留两种动作语义。三带二只比较三张。 |
| R09 | 自由领出必须出牌。跟牌可选择过牌，即使有可压动作也允许过牌；之前过牌不禁止本圈后续再接。任何合法盖牌都重置本轮过牌集合。 |
| R10 | 跳过已出完者。当前最大出牌者之外的所有仍有牌玩家均过牌后，本圈结束；最大者有牌则继续领出，否则由其仍有牌队友接风。队友已结束时由最大者的下一仍有牌座位领出。结束圈后清空待压动作与过牌集。 |
| R11 | 同队包揽头二游立即结束，仅记录两位真实名次，另两位不伪排名；否则第三位出完即结算，余下者记第四。头游所在队胜利，其队友名次为 2/3/4 时升级收益为 3/2/1。 |
| R12 | 第一训练目标为单副牌团队胜负：胜队 +1，负队 -1。level_gain 独立记录，不能冒充完整比赛收益；不含中间塑形奖励。 |
| R13 | 非当前行动者、结束后行动、手牌外/重复牌、错误声明、不能压制、领出过牌、过期版本均拒绝，拒绝不得改变状态。 |
| R14 | 策略可见自己手牌、级牌、座位、每家余牌张数、公开行动与真实完成名次；不能看到隐藏牌、随机种子或可恢复隐藏牌的摘要。全体余牌数公开是数字研究环境约定。 |
| R15 | 仅将同点同花色不同副本的互换视为等价。候选集合保留花色差异、配牌消耗、牌型声明及 main_rank 差异，不启发式截断。实体动作验证仍接受合法的另一副本。 |
| R16 | 全信息研究回放必须显式包含 visibility=research_full，保存初始手牌、规则/动作版本、行动与每步摘要，重演校验。玩家观测绝不包含该回放。 |

规则接口：`enumerate_actions(hand, level) -> list[Action]` 仅枚举非 pass；`beats(candidate, incumbent, level)`；`validate_action(action, hand, level) -> bool`。牌型字符串：single/pair/triple/full_house/straight/pair_chain/triple_chain/bomb/straight_flush/joker_bomb。

工程选择：对非花色牌型，配牌解释的 suit=-1，消除无意义花色声明；对同花顺指定 0..3。main_rank 为主体点数或连续牌型最大点数（低 A 序列分别为 5/3/2），不能预先升位。

来源与边界：国家体育总局公开页面确认竞赛规则体系存在，但本轮未获得可完整核对的官方技术条文。因此本规格中的可配置研究约定（双配牌、普通顺子声明、余牌数全公开、首攻）以项目定义为准。参考仓库只做差异审查，没有复制源码或权重，详见 reuse-review.md。
