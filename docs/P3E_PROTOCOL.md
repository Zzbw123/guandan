# P3e 开发集诊断、固定训练规模对照与独立验证

2026-09-26 总控冻结，版本 gd-p3e-scale-v1。只改变累计训练手数，不改规则、编码、网络、奖励、epsilon、学习率或采样算法。沿用 GPUTrainer 与外部 GPUInferenceGuard。历史源码及证据保留。

## 问题与预算

先在开发 seed108000..108025（26 原始发牌，每级 2 组）诊断 P3d 固定 400 手候选对 greedy，并跑 greedy 对 greedy 参考，各 208 局。4 轮换 × 2 换队完整保留。统计可选让牌、强制过牌、盖过队友、一次出完机会及遗漏、<=5 张残局中的可选让牌、首攻和动作类型。分子分母同时报告；行为频率本身不等于决策错误或因果解释。

训练初始化固定 314370、314371、314372。每个初始化使用相同开发 seed105000..106599，级牌 2+i%13、首攻 i%4；4 环境同步训练到 1600 手，保留第 100/200/300/400 wave。400 手检查点是同一轨迹的预先指定前缀，与 1600 手构成配对；没有独立训练的重复 400 手分支。训练共 4800 手，1200 wave。各配置 epsilon0.1、lr0.001、batch256、chunk1024。随机种子314373打乱三个训练初始化顺序；314374打乱六个开发评测作业顺序，全部训练完成后才比较开发胜率。不得按中途结果追加预算。

六个检查点各在同一26组开发发牌对greedy评测208局，共1248局。每个初始化报告400→1600胜率差（百分点）；先在每个原始发牌内配对，再按级牌分层bootstrap5000次、seed314375。各区间为固定初始化下的描述性点态区间，不是跨初始化总体推断或多重检验。报告3次初始化的均值/范围/标准差和全部结果，不能把3×26当独立发牌。3个初始化和26组是资源预算，没有80%功效或长期稳定性声明。在线训练损失仅反映各批自生成样本，不能当成可比验证损失。

## 唯一验证候选与数据边界

事先指定初始化314370的1600手检查点为唯一验证候选，不按开发胜率择优。验证 seed202000..202064：65原始发牌、每级5组，每组8变体，对greedy/random/team各520局，总1560局。使用前扫描历史seed记录并保留范围占用证据；生成检查点后、任何验证对局前绑定SHA256。202000..202064完成后标记已查看。201000..201064属于旧已查看验证；9000000..9009999继续封存。

唯一确认性主比较为固定候选对greedy，95%分层发牌组bootstrap5000次、seed314375，门槛点估计>=55%、非退化区间下界>50%，且所有工程检查通过。其余对手是描述性对照。通过只标VALIDATION_GATE_PASSED，不自动晋级或替换主基线。P3d和P3e验证使用不同发牌，不用两者的胜率差作训练改善证据。

## 证据与边界

所有评测沿用policy RNG271828；完整合法候选不裁剪。策略只收到PlayerObservation和合法Action列表，研究回放仅在环境和离线审计使用。GPU启动60秒/每请求2秒硬时限，基线返回后2秒软检查；每局1000步。各作业独立子进程总截止1800秒；失败中止，记录保留，不删失败局继续统计。
