# P3c GPU 同步批量训练与恢复协议

2026-09-26 总控事前确定；版本 `gd-gpu-wave-v1`。延续 P3b GPU 路线。本包只验收训练工程；正式训练预算和独立棋力评测另行冻结。沿用项目 artifacts 证据目录，不改原规则、CPU 学习实现与历史注册文件。

## 算法和信息边界

复用 gd-features-v1 / gd-dmc-network-v1。策略入口仅接收 PlayerObservation 和完整合法动作；发牌 seed、全状态、研究回放仅在环境管理层。CUDA float32，TF32关闭，确定性算法，单CPU线程。原始候选顺序不变、等分选首项、不裁剪合法候选。

采用单进程、多环境同步 wave：固定4个环境，每个未终局环境每轮走一步，非探索请求合并进行GPU评分。一次编码和上传动作数组，分块限制激活内存，完成后统一回传结果。环境规则仍在CPU运行；不宣称多进程或异步采样。每wave参数冻结至全部4手终局及完整回放通过；按环境顺序汇总样本，用独立策略RNG打乱，一遍minibatch MSE/Adam。团队终局±1回报，gamma=1，无跨wave重用。该更新频率与P3a每局更新不同，显式版本化，不声称训练轨迹相同。

第w个wave行为版本w-1，完成更新后版本w。下一wave读取同一网络的最新参数，无异步actor和陈旧权重。遇到采样、回放或更新异常，实例进入不可保存/不可继续状态；从上个已提交wave检查点重做失败wave。

## 检查点契约

仅在完整成功wave边界保存网络、完整Adam、独立Python策略RNG、torch CPU RNG、全部CUDA RNG、配置、累计episodes/updates/waves、已用开发seed、协议/规则/特征/网络版本、源码和精确运行时。仅本机同版本/同设备承诺恢复；不支持局中恢复、跨设备迁移或不兼容源码恢复。

先写唯一临时目录，数据和manifest各自flush/fsync，再原子重命名为目标目录。目标已存在必须拒绝；中断产生的临时目录不自动当作检查点。weights_only反序列化，校验文件hash/大小、manifest与载荷一致、版本/源码/运行时、计数与seed、参数/Adam形状类型有限性、RNG结构。只有完成所有校验后恢复全局RNG。哈希用于完整性追踪，不冒充外部可信签名。

## 固定有界验收预算

初始化seed314260，epsilon0.1，lr0.001，batch256，score chunk1024，num_envs4。开发seed103000..103015，级牌2+i%13、首攻i%4，共4wave/16手。第2wave后保存，连续执行后2wave；再由新Python进程重载第2wave并执行后2wave。比较全部轨迹摘要、损失、计数、模型、Adam、Python/CPU/CUDA RNG逐位一致。复跑不增加独立手数。评测/验证/保留测试集均不执行。

高候选8769项：完整覆盖，批量评分与既有CUDA逐请求实现容差atol1e-5/rtol1e-4比较；在同一运行内交替测量5次，仅报告当前实现墙钟，不把历史硬件状态不同的耗时相除当作速度提升结论。必须同时验证多个不同观测的批量请求，防止只测单请求掩盖索引问题。

故障验证：损坏/截断文件、重哈希但错误版本/计数/seed/Adam/RNG、未完成wave保存、保存提交中断、已有目录拒绝覆盖、采样故障后从旧检查点重做。总控独立复算报告、重载最终检查点、核对源码ZIP及P2/P3a/P3b注册文件。任何门槛失败保留FAIL证据，不签署通过。
