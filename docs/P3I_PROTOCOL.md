# P3i 教师偏好误差分解与中心化目标工程协议

日期：2026-09-26。范围：既有开发评分诊断与CUDA数值工程验证；不启动正式训练或新胜率评测，不使用验证/保留测试发牌，不晋级模型。

## 固定输入与统计单位

只使用P3h fidelity的原128个多候选观察（4174候选），其选择规则为P3f teacher-314380前200手轨迹中前128个多候选决策。六模型为control/aux × 314380/314381/314382。保留每个状态、每个模型、每个完整候选，不按结果过滤。输入scores、report、controller-audit、原轨迹和模型manifest/payload在运行前绑定SHA256；重新重建状态/完整候选/教师分数，并用六模型直接forward核验。

每个状态候选等权，跨状态等权；4174个候选、128个状态均不视为独立发牌样本。不计算总体置信区间，不将该有目的子集外推为全状态或棋力。

## 误差恒等式

令模型输出q、既有min-max教师目标t（范围[-0.8,0.8]），均值仅在当前状态的全部合法候选上求取。

`MSE = mean((q-t)^2) = (mean(q)-mean(t))^2 + mean(((q-mean(q))-(t-mean(t)))^2)`。

输出逐状态原MSE、均值差、有符号偏移、偏移平方项、中心化误差、恒等式残差，以及原teacher top-1和标准化遗憾。汇总分别对128状态求平均；偏移占比为平均偏移平方/平均MSE，不能替换为有符号偏移均值的平方。中心化目标不作再次min-max、不裁剪、不归一到概率。

## 独立的中心化辅助原型

`L_aux = mean_states(mean_full_candidates((q-t-mean_candidates(q-t))^2))`。

每状态使用全部候选的全局均值，禁止按chunk各自中心化。采用两遍forward：第一遍无梯度收集完整误差和均值；第二遍按chunk累积梯度。均值detach的依据为完整中心化残差和为零，导数为`2*(q-t-mean(q-t))/(状态数*该状态候选数)`。限定既有确定性DMCNetwork，无dropout/可变forward状态；两遍间不更新参数。原型仅加梯度，不清梯度、不调用Adam。所有请求先完成结构和有限性校验；调用者负责合法集合完整性。发生错误不得继续使用半完成梯度。

单候选贡献严格为0，但保留在状态总数分母中。对每状态输出或目标加常数在数学上不改变损失或输出梯度；这不等同于tanh网络参数平移不变性，也不代表保留动作排名或提高胜率。

## 固定验收门槛

- 磁盘全部768条状态模型记录独立复算，恒等式绝对误差<=1e-12，输入/源码哈希保持一致。
- 实际CUDA float32：不等候选数、多状态、单候选、尾chunk、多种chunk；中心化稠密autograd与分块损失/参数梯度相符，梯度atol=2e-6、rtol=2e-5。
- 同时累加选中动作DMC项及0.1辅助项后，联合稠密梯度和一次Adam更新相符；数值测试不构成正式训练。
- 8769高候选全部覆盖；单候选梯度零、零权重不影响已有梯度；平移不变与输出梯度和为零。
- 拒绝空输入、非法chunk/权重、非有限值；审计拒绝缺行/重复/错误分母/错误分解/假晋级/输入哈希改变。
- 已验收源文件保留原hash，新源码和回执单独存档。失败保留证据，不覆盖正式结果。
